# Assets/fonts

Game memakai font bawaan Godot supaya bisa dijalankan tanpa aset tambahan.
Semua teks memakai ukuran dan warna dari tema `assets/ui/theme/TapakNusa.tres`.

Bila ingin memakai font sendiri:

1. Simpan berkas font (`.ttf`/`.otf`) di folder ini.
2. Buat `FontFile` baru dan setel sebagai `default_font` pada
   `assets/ui/theme/TapakNusa.tres`.
3. Periksa kembali ukuran huruf pada panel dan kotak dialog.
